# Instalação

## Mobile (recomendado)
```bash
cd mobile
npm install
npm run dev      # http://localhost:5173
npm run apk      # gera ../dist-apk/*.apk
```

## Desktop
```bash
npm install
npm run dev      # Next.js
npm run package:portable
```

## Android
Instalar APK em `dist-apk/`. Permitir fontes desconhecidas.
Primeiro acesso: autorizar permissões do dispositivo.
